# 数据定义

## 响应文件

上传单次测量的预分带响应 CSV。应用对同文件的不同频带分别计算。整个文件使用 UTF-8（含 BOM）或 GB18030，表头可重排。最多 8 MiB、100000 条表头后逻辑记录。样例为合成回归数据，带有效频带、缺点、截断、低动态范围和两段斜率。

| 字段 | 定义 |
|---|---|
| `band_hz` | 中心频率，支持 63 至 8000 Hz 的八个倍频程中心 |
| `sample_index` | 零起点整数，期望连续至 `expected_samples - 1` |
| `rate_hz` | 该预分带序列的时间基准，1000–192000 Hz |
| `expected_samples` | 声明采样数量，64–80000 |
| `unit` | 振幅单位 Pa、mPa、V 或 mV |
| `gain_db` | 仪器振幅增益，−60 至 100 dB |
| `pa_per_v` | 电压至压力校准系数，0.0001–10000 Pa/V。压力记录留空 |
| `amplitude` | 带符号、有限振幅，可用科学计数或全角字符，支持真实零值。空白或空值标记隔离 |
| `note` | 原样备注，可含换行 |

频带内校准字段须一致。重复点按规范化幅值和校准元组确认，同配置同幅值取最早物理记录，不同值整带隔离。中间缺点、尾部不足和记录超出声明长度单独报因。识别不出频带的坏行单计行勾稽。可归属的坏行隔离整带，避免补点直接改变回归结果。

## 信号与拟合

- 电压先按灵敏度换算至帕。增益是振幅量，除以 `10^(gain_db/20)`。时间零点为第一处绝对振幅最大点，之后按采样序号除以采样率。采样原始行号随证据保留。
- 取峰值后压力平方。用最后 15%（至少 10 点，短序列按实际点数）的五段均方中位数估计平稳噪声功率 `N`。反向累加 `p² - N` 并从后向前取非负运行最大值，得到随时间非增的剩余能量。物理初始能量等于累加值除以采样率，单位 Pa²·s。曲线使用 `10 log10(E(t)/E(0))`。能量耗尽位置为 JSON `null`。噪声底的横线是单采样噪声功率相对于起点累计能量（Pa² 样本）的 dB 读数。
- 阈值使用高于噪声 10 dB 的块平均功率。拟合范围在首次连续两个约 10 ms 的块低于阈值之前截止，并排除测噪尾段。零能量、峰后不足 40 ms 与深度不够均保留原因。T20 需要至少 25 dB 的可用深度，T30 至少 35 dB。
- 区间端点从曲线交点线性插值得到。T20 回归 −5 到 −25 dB，T30 回归 −5 到 −35 dB。内点为首个达到 −5 dB 的样本起，至首个达到下界的样本之前，至少 8 个点。最小二乘斜率须为负，R² 至少 0.96。公布值为 `RT60 = -60 / slope`，秒。屏幕显示至毫秒，勾稽比较使用未截断的数值。
- 图表为展示降低点密度，计算使用每个样本点。出具单档时保留该档，另一档给原因。两档都有时，`abs(T20-T30)/T30 > 15%` 标差，15% 的边界允许浮点计算误差。

## 频带、采样与归档

`识别频带 = 可拟合 + 动态范围不足 + 隔离`。至少一档拟合成功归可拟合，否则深度不足归动态范围不足，连续性、零能量、尾段过短或拟合质量异常归隔离。另对比频带身份集合与采样数量。采样行等于采信、隔离、重复、空白和重复表头之和。

归档记录由源文件原字节摘要和规则版本定位。运行清单含 UTC 创建时间、耗时与证据摘要。重跑读原始文件、重算并校验结果。导出保留采信与隔离、校准、图表点、回归系数和窗口、噪声与勾稽结论。

## 复核交付包

验收后交第三方复核的是**最小可复算证据集**，不是原始收件。包格式 `hall-decay-evidence/1`，由 `GET /api/runs/{id}/export` 下载，`GET /api/runs/{id}/package` 供工作台预览（不含采信振幅）。

- 只带重算所需的采信频带：校准元组（采样率、声明长度、单位、增益、灵敏度）与每个采信点的来源行号 `lines`、规范化振幅 `amplitudes`。据此可独立重算曲线、拟合、噪声与勾稽。
- 被挡记录只保留来源行号、行段、采样数与排除原因码；**不复制任何未采信行的振幅原文**（矛盾振幅也不随包带出），复核方按行号回原档核对。缺点不与记录等长，故缺采样点给 `gaps`：缺口两侧最近采信点的 `before_line` / `after_line`。
- `intake` 段保留归档的收件计数、被挡频带与行号。`scope` 段显式说明带了什么：`carries_raw_recording: false`、采信频带与点数、被挡行数、空白行与重复表头行号、`contents_included: false`。
- `conclusion` 段为紧凑结论（每带状态、T20/T30、标差、噪声深度、勾稽汇总），供人眼核对；完整图表曲线不随包发。
- `archive.result_digest` 为归档证据摘要；`digest` 为整包摘要（去掉 `digest` 自身后规范化计算）；导出响应头 `X-Evidence-Digest` 同值。
- `checks.recomputed_matches_archive` 在打包时已用包内数据重算整份结果并与归档摘要比对，不一致即拒绝出包。复核方重算应逐一命中 `archive.result_digest`。
- 不带存储即可独立复核：`python -m app.modules.m7_archive.bundle <证据包.json>`，输出 `recomputed_matches_archive`、`conclusion` 与勾稽汇总；退出码非零表示不一致或已失效。

同一归档重复打包逐字节相同，不新增记录；重跑按 `source_id + 规则版本` 幂等复用。规则版本更新后，旧包仍可下载，但 `valid: false`、`stale.code = RULE_VERSION_CHANGED`、`scope.recomputable = false`，不再随包带采信振幅，也不冒充当前规则的重算结果，须按当前规则重跑后再交付。

当前接收完成分带的序列，未实现宽带滤波、混响室或标准的合规认证。尾段噪声按平稳模型估计，存在持续背景变化时应使用测量设备的复测结果复核。
